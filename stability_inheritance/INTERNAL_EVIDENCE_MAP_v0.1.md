## Cross-project pattern currently visible

The recurring program-level observation is not "χ is everywhere." It is that the minimum adequate representation changes by system and task. Scalar χ may be admitted, insufficient, nonidentifying, or refused; modal/vector Χ may remain informative; and separate conglomerate/system Χ_sys may add information that neither scalar nor base modal structure contains.

This recurrence is post-result program evidence. It generates Stability Inheritance hypotheses but is not itself prospective confirmation of them.

## Candidate inheritance classes

The current evidence supports separating at least four candidate inheritance questions:

1. **Scalar inheritance:** does an admitted scalar coordinate survive or transform under embedding?
2. **Modal inheritance:** does carrier, mode, eigenspace/subspace, participation, or equivalent resolved structure survive or transform?
3. **Conglomerate inheritance:** does a system-level organizational relation in Χ_sys persist, reorganize, or constrain the descendant system after embedding or scale change?
4. **Cross-level inheritance:** does lower-level χ or Χ provide nonredundant information about higher-level Χ_sys or realized perturbation/recovery behavior beyond the strongest native higher-level model?

These are candidate classes, not a final ontology.

## Closure/memory prior-art firewall

Mori-Zwanzig and generalized-Langevin coarse-graining already provide a formal route by which unresolved lower-level degrees of freedom influence resolved higher-level variables through memory and fluctuating terms. Therefore "lower-level history leaves a memory in higher-level dynamics" is not by itself Stability Inheritance novelty.

For SI, closure/memory is treated as a native comparator or mechanism candidate, not automatic inheritance. A stronger inheritance relation must identify a stability-relevant lower-level object, establish its carrier or transformation correspondence, and show prespecified nonredundant value for higher-level Χ_sys or realized response beyond an adequate native closure model. If Mori-Zwanzig, GLE, state augmentation, or another standard closure already captures the frozen task equally well, the SI result is EQUIVALENT or NO_ADDED_INHERITANCE_VALUE.

## Legacy physical candidates from prior SymC work

### Noughts / electromagnetic lineage

Use only as a fresh native-physics reconstruction candidate. The old language about an electromagnetic substrate, vacuum constants, cosmological cascade, and universal χ cannot be imported as evidence. Revised-SI metrology also removes ε0 and μ0 numerical values as credible fundamental substrate evidence. The residual SI question is whether an identifiable lower-level gauge/electroweak structure passes through a licensed physical transformation and adds nonredundant information about later electromagnetic organization beyond standard QFT/EFT/RG treatment.

### Neutrino systems

Treat first as a modal/environmental reorganization problem. Matter-induced open-system decoherence is already prior art, so the key discrimination is whether changing environment and basis merely changes the instantaneous native state, or whether identifiable prior modal organization/history constrains the descendant state beyond the standard Hamiltonian, matter profile, initial state, and admitted decoherence variables. A null result would be a useful ENVIRONMENTAL_REORGANIZATION_WITHOUT_INHERITANCE case.

### Black-hole ringdown

Treat first as a native modal laboratory and known-truth qualification system. Progenitor dependence of ringdown excitation amplitudes/phases is already established prior art, so SI cannot claim that discovery. Quasinormal mode frequencies, damping, overtones, angular structure, excitation amplitudes, and mode families instead allow direct testing of whether χ / Χ / Χ_sys separation recovers the known distinction between remnant-native spectra and source-conditioned excitation, and whether it adds anything beyond standard ringdown models. Spectral similarity alone is not lineage or inheritance.

## Immediate implication for Stability Inheritance

The strongest current residual is not a generic statement that stable systems are hierarchical. The sharper candidate is:

> Given independently characterized lower-level χ and/or Χ, and an independently characterized higher-level native system, does the lower-level architecture add nonredundant information about higher-level Χ_sys, perturbation response, recovery, reorganization, or accessible stable regimes beyond the strongest native higher-level representation?

A stronger mechanistic claim additionally requires a frozen carrier or transformation path and a counterfactual/intervention showing the predicted higher-level change.

## Current stop rules

- If lower-level information adds no prespecified value beyond the higher-level native model, classify no useful inheritance relation for that task.
- If only scalar similarity survives but carrier or transformation specificity fails, do not promote beyond influence/similarity.
- If modal correspondence survives but system organization does not, retain modal inheritance without promoting conglomerate inheritance.
- If system-level organization is informative but cannot be traced to the proposed lower-level carrier, retain Χ_sys structure without claiming inheritance.
- If a simpler native representation is sufficient, report EQUIVALENT or no added Stability Inheritance value rather than adding layers.
