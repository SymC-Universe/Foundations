# DESI DM/DE ↔ Stability Inheritance Overlap Firewall v0.1

**Date:** 2026-10-01
**Governance:** SymC GOM v1.0 + mandatory Continuity Hardening Addendum
**Purpose:** Permit efficient reuse of DESI source material while preventing duplicate-evidence inflation, claim leakage, and accidental merger of the DM/DE and Stability Inheritance scientific questions.

## Shared material

The two lanes may reuse the same verified DESI DR1 posterior chain families, source receipts, checksums, transport records, and basic chain-loading infrastructure.

In particular, both currently touch the flat-\(\Lambda\)CDM baseline and DESI \((\mu,\Sigma)\) modified-gravity posterior family.

This shared provenance is **not independent evidence**.

## DM/DE lane

Primary scientific role:
- characterize cosmological parameter behavior and physical-model sensitivity;
- compare \(\Lambda\)CDM, \((\mu,\Sigma)\) modified gravity, CPL dark-energy histories, and neutrino adversaries;
- study parameter shifts, degeneracies, redshift histories, background/growth implications, and robustness to physical model extensions.

Representative DM/DE quantities:
- \(\mu_0\), \(\Sigma_0\);
- \(w_0,w_a\);
- \(\Omega_m\), \(\sigma_8\), \(S_8\), \(H_0\);
- neutrino mass;
- derived dark-energy density/equality/acceleration histories.

DM/DE interpretation ceiling is cosmological/physical-model analysis. It must not use SI representation tests as independent cosmological evidence unless a future protocol explicitly licenses that transfer.

## Stability Inheritance lane

Primary scientific role:
- qualify representation sufficiency and loss;
- test scalar versus distributed vector information;
- test residual composition after scalar removal;
- test additive versus pairing-specific cross-block information;
- classify redundancy, added value, pairing specificity, indeterminacy, native-framework equivalence, or refusal.

The current DESI SI tests intentionally exclude model-only \(\mu_0\) and \(\Sigma_0\) from classifier inputs.

Representative SI objects:
- shared background/growth coordinates \(B+G\);
- scalar summed tracer fit \(S\);
- tracer-response vector \(T\);
- scalar-removed residual composition \(R\);
- additive representation \(A\);
- interaction representation \(X\);
- pairing-destroyed control \(X_{\rm shift}\).

SI interpretation ceiling is representation qualification. A positive SI result is not model preference, modified-gravity evidence, dark-matter/dark-energy ontology, or a new cosmological mode.

## Non-independence rule

Any result derived from the same DESI posterior families belongs to one shared evidence family for independence accounting.

Therefore:
- DM/DE MG results and DESI SI Results 1-3 must not be counted as separate independent replications;
- cross-domain SI summaries may cite DESI only once at the dataset/family level even when multiple internal tests are reported;
- manuscript language must distinguish multiple analyses of one evidence source from replication on an independent source.

## Cross-lane transfer rule

Allowed without a new scientific gate:
- source hashes and receipts;
- transport provenance;
- chain parsing;
- already-public native parameter definitions;
- computational infrastructure.

Requires a new explicit gate:
- using DM/DE-derived physical conclusions as SI labels or features;
- using SI classifier/interaction outcomes as support for MG, DE, DM, or neutrino physics;
- using a DM/DE model family as an SI adversary if it was not prospectively frozen for the SI task;
- treating an SI representation result as evidence for a dark-sector mechanism.

## Current overlap adjudication

**DATA/PROVENANCE OVERLAP: YES**

**SCIENTIFIC-ENDPOINT DUPLICATION: NO, at current frozen designs**

The present v0.1d SI cross-block test asks whether observed \(B+G\)-to-\(R\) pairing contributes held-out model-family information beyond additive and pairing-destroyed controls.

The DM/DE modified-gravity analysis asks how the added \((\mu,\Sigma)\) freedom changes cosmological posteriors and degeneracies.

These are distinct scientific endpoints even though they use the same baseline/adversary chain families.

## Main risk

The main risk is not duplicate computation. It is **double interpretation**:
1. counting the same DESI source twice as independent support;
2. allowing a representation result to mutate into a physical dark-sector claim;
3. choosing later SI model families because they gave interesting DM/DE results.

All three are prohibited without a new prospective gate.

## Future coordination

After both lanes close their current frozen stages, a joint synthesis may ask whether SI representation diagnostics reveal anything not already captured by native DM/DE posterior geometry.

That synthesis must treat DM/DE as the native cosmology comparator, not as independent corroboration.
