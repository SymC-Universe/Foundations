## Pass A: methods / identifiability attack

### A1 — BLOCKER — The draft can be mistaken for a novel inheritance experiment even though standard component-mode/dynamic-substructuring theory already predicts component-to-assembly behavior.

**Basis:** component-mode synthesis, experimental dynamic substructuring, approximate bisimulation, and stability-preserving reduction already formalize component/assembly prediction and property preservation.

**Resolution:** first cycle must be labeled P0-Q KNOWN-TRUTH PHYSICAL QUALIFICATION. It cannot promote a novel inheritance claim. Its job is to test whether SI representation and refusal labels reproduce known native distinctions and fail safely.

### A2 — MATERIAL — Χ_con risks circularity if it is constructed from the same parent modes used as predictors.

**Resolution:** Χ_con ground truth must be defined from direct assembled-system measurements after predictions are frozen: assembled FRF/state-space response, directly identified assembly modes/subspaces, transfer/energy-response measures, and frozen transient-response metrics. Parent Χ may predict these objects but may not define them.

### A3 — MATERIAL — The "higher-level native model versus native-plus-lower-level" residual cannot be cleanly tested if the native comparator is CMS, because CMS already uses lower-level component information.

**Resolution:** distinguish two purposes:
1. physical qualification benchmark: scalar-only versus modal versus CMS/full-native prediction of directly measured assembly outcomes;
2. later SI incremental-value P1: a separate domain/test where the strongest higher-level baseline can be defined without already containing the proposed lower-level object.

The first physical cycle does only (1).

### A4 — MATERIAL — Changing coupling location can alter parent boundary conditions, attachment mass, preload, or joint stiffness and thereby masquerade as a carrier effect.

**Resolution:** interface hardware, preload, attachment mass, and coupling stiffness require independent measurement/standardization. Parent isolated characterization must be repeated after each assembly/disassembly sequence to quantify drift. Exceeding a preregistered drift margin invalidates that contrast.

### A5 — MATERIAL — Experimental state-space models can be non-passive or nonphysical because of noise and identification error.

**Basis:** experimental dynamic-substructuring literature reports non-passive identified components, interface-rank requirements, sensor artifacts, and sensitivity to interface modeling.

**Resolution:** add pre-assembly reciprocity, passivity/energy-dissipation, rank, sensor-health, and physical-consistency gates. A failed gate is mechanical/methodological refusal, not a scientific inheritance result.

### A6 — MATERIAL — Q3 damping manipulation is likely to contaminate stiffness/boundary conditions.

**Resolution:** remove Q3 from the first frozen cycle. Retain as a later optional extension after an independent calibration demonstrates that damping can be changed without material change in modal geometry or boundary condition.

## Pass B: novelty / Hunting Friction attack

### B1 — BLOCKER — Passing Q1/Q2 would not show that Stability Inheritance adds scientific information beyond CMS; it would mainly show that SI can redescribe standard substructuring.

**Resolution:** explicitly make "SI adds no information beyond CMS" an expected successful benchmark outcome: NATIVE_FRAMEWORK_EQUIVALENT. Do not call that inheritance confirmation.

### B2 — MATERIAL — The plan does not yet define a scientific failure of the SI framework itself.

**Resolution:** add framework-level failure criteria:
- layer labels cannot be assigned reproducibly under representation changes that native theory regards as equivalent;
- SI-specific distinctions do not change any prediction, refusal, identifiability decision, or boundary relative to the native comparator across the planned failure cases;
- outcome classes depend materially on arbitrary normalization/basis choices;
- the χ / Χ / Χ_con separation cannot be operationalized without using outcome information.

If these occur, classify FRAMEWORK_NO_ADDED_VALUE or FRAMEWORK_NOT_OPERATIONAL for this domain.

### B3 — MATERIAL — "Carrier specificity" may simply duplicate causal-abstraction intervention consistency and substructuring interface mapping.

**Resolution:** first cycle tests compatibility with those established frameworks, not novelty. Any later mechanistic SI novelty must identify a stability-specific empirical decision or boundary not already represented by causal abstraction/CMS.

### B4 — MATERIAL — Analytic label-scramble controls are weaker than physical alternative-carrier controls.

**Resolution:** keep label-scramble as code validation only. Q1 alternate interface is the primary physical specificity control. Do not promote a carrier claim from label scrambling alone.

### B5 — MATERIAL — Near-degenerate modes create one-to-one mode matching instability.

**Resolution:** freeze principal-angle/subspace comparison as primary in any crowded sector; individual eigenvector matching is secondary and may refuse.

### B6 — MATERIAL — A one-apparatus result cannot establish transport.

**Resolution:** no P1 or general inheritance claim from the first cycle. Any later promotion requires an independently frozen replication or a materially different apparatus/domain.
