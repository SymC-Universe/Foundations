# Exploratory class-crossing lead v0.1

**Status:** POST-HOC / HYPOTHESIS GENERATION ONLY
**Timing:** after `PASS_ADVERSARIAL_CLASS_MONOTONICITY` for the frozen 512-case near-boundary H3 panel.

This note does not alter or invalidate the H3 result. H3 was defined only on the 512 cases selected by its preregistered physical-only near-boundary ranking rule and passed with zero crossings.

After H3 closed, an exploratory equation-level search was used to ask whether class preservation might nevertheless fail elsewhere in the exact same measured-qubit model family. This search is not prospective evidence and may not be cited as confirmation.

## Exploratory lead

One numerical input found after H3 closure was approximately:

- `gamma = 15.261790719112119`
- `kappa = 306.3005952717552`
- `omega = 283.6957263727396`
- `eta = 0.14947534294837447`
- Bloch `x = -0.3058824220939059`
- Bloch `z = +0.9434732251313244`
- `y = 0` for the active-plane diagnostic

The physical second-moment spectrum had dominant real part approximately

`alpha_phys = -1.3734015297386062`,

while the same-record spectrum had

`alpha_rec = +4.091514790714528`.

Using scale `R=gamma+kappa+omega+eta*kappa`, the normalized values were approximately

- physical `-0.002109542053070611`;
- record `+0.0062845586850448915`.

Thus this post-hoc lead is consistent with a genuine STABLE -> UNSTABLE class crossing.

## Exploratory region

A separate exploratory targeted scan suggested such cases are rare but cluster where:

- `kappa/gamma` is several to tens;
- `omega/gamma` is several to tens;
- measurement efficiency is moderate rather than extreme;
- the Bloch state lies near the measurement axis, `|z|` close to 1;
- `x*z < 0`.

This region was identified after seeing exploratory outcomes and therefore is used only to define the next fresh preregistration.

## Anti-circularity consequence

No universal class-preservation theorem may be claimed from H3.

The next phase must use a new seed, a frozen target-region generator, physical-only Stage-A selection/freeze, and same-record Stage-B reveal. The exploratory candidate above must not be included in the prospective panel or counted as evidence.
