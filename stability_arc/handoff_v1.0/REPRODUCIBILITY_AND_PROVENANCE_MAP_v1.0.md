## 5. Reproduction rule

A future rerun of a closed phase is a reproduction exercise, not new prospective evidence, unless a new preregistration defines genuinely new evidence.

Never alter a historical gate to make a reproduction pass.

If numerical software versions change, report the new environment and compare to the frozen result rather than silently replacing it.

## 6. Package integrity

`MANIFEST_SHA256.txt` hashes the handoff payload files.

The Git history is the durable source of the underlying scientific files. The downloadable handoff ZIP is a convenience copy, not the sole canonical repository.
