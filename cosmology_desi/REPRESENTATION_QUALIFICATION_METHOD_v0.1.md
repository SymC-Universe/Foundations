# Representation Qualification Method v0.1

**Status:** FROZEN PROSPECTIVE METHODOLOGY DRAFT  
**Date:** 2026-09-30  
**Scope:** Cosmology first; portable only after domain-specific validation  
**Scientific firewall:** Method specification only. No active computation is modified.

## Purpose

Determine the minimum representation that is scientifically justified for a frozen question before physical interpretation.

The method does not assume that more structure is better. It can terminate at scalar adequacy, resolved/modal necessity, coupled/conglomerate necessity, REFUSE, or NEED MORE INFO.

## Decision states

- **SCALAR_ADEQUATE** — a scalar/compressed representation preserves the information required for the frozen question.
- **RESOLVED_REQUIRED** — scale/redshift/modal structure adds material predictive or discriminating information that the scalar loses.
- **COUPLED_REQUIRED** — the relation among already-qualified components adds material information beyond their marginals.
- **REFUSED** — the proposed representation is redundant, non-identifiable, model-imposed, unstable, leakage-prone, or adds no incremental value.
- **NEED_MORE_INFO** — the distinction is scientifically meaningful but current data, covariance, resolution, or holdout coverage cannot decide.

## Mandatory gates

### Q0 — question freeze
Define the scientific target, held-out endpoint, candidate representations, admissible adversaries, and decision thresholds before evaluation.

### Q1 — native-model sufficiency
Reject any candidate whose apparent information is algebraically or deterministically generated by the native model variables already in use.

### Q2 — information sufficiency
For candidate representation R, quantify whether it preserves information relevant to the frozen target using at least one native diagnostic appropriate to the problem: mutual information, likelihood/Fisher loss, posterior predictive performance, calibrated classification/discrimination, or an equivalent preregistered metric.

### Q3 — lower-order challenge
Higher-order representation R_(n+1) is not admitted unless it demonstrates incremental value over R_n at matched data, splits, nuisance handling, and complexity controls.

### Q4 — matched adversaries
Repeat under dataset-matched plausible alternatives. Cosmology minimum set when applicable:
- LambdaCDM / GR;
- dynamical DE;
- free neutrino mass;
- modified gravity;
- dark-sector interaction;
- sample/systematic variants.

### Q5 — misspecification and leakage
Test whether gains are explained by model misspecification, smoothing, priors, feature leakage, nuisance differences, or unequal effective complexity.

### Q6 — held-out falsification
Evaluate only on held-out mocks, realizations, scales, redshift blocks, tracers, or datasets frozen before result inspection.

### Q7 — disposition
Assign exactly one primary state from the decision-state set and preserve failed gates.

## Incremental-value rule

A higher representation is not promoted because it is richer or visually informative.

For a target Y and lower-order representation R0, a higher representation R1 is admitted only if it provides reproducible incremental information conditional on R0:

\[
\Delta \mathcal I
=
\mathcal I(Y;R_1\mid R_0)
>0
\]

or an equivalent preregistered predictive/discriminating gain that survives uncertainty and adversarial controls.

For a coupled representation C(A,B), the relation itself must add information beyond both marginals:

\[
\mathcal I(Y;C(A,B)\mid A,B)>0.
\]

The exact estimator need not be mutual information; this equation states the scientific requirement.

## Redundancy control

The method is refused as a distinct contribution if standard existing tools produce equivalent decisions with no added calibration, interpretability, refusal behavior, or protection against false physical declarations. Required comparators include, where applicable:
- standard information criteria / Bayes factors;
- posterior predictive checks;
- null/consistency tests;
- standard compression diagnostics;
- information-theoretic summary sufficiency;
- model-misspecification tests.

## First validation challenge

Use matched cosmological cases at three information levels:

1. scalar/compressed background summaries;
2. resolved full-shape / scale/redshift information;
3. joint background + growth information.

Include at least:
- one case where compression should be adequate;
- one case where resolved information should matter;
- one deliberately under-resolved case that should return NEED_MORE_INFO;
- one coupled-representation candidate that should be REFUSED unless the relation adds held-out value.

Success requires correct calibration of both promotion and refusal, not simply tighter constraints.
