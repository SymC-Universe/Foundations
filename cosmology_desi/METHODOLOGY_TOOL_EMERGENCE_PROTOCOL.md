## Purpose

The program has repeatedly produced a methodological instrument before, and sometimes in addition to, a computational instrument. This protocol makes that structure explicit for the DM/DE investigation.

The primary product is not assumed to be software. The first admissible tool is the methodology itself: a falsifiable decision procedure that determines what representation the evidence supports, what interpretations are refused, and what additional information is required. A computational diagnostic is promoted only if repeated empirical use shows that enough of that procedure can be executed reproducibly without replacing scientific judgment with hidden assumptions.

## Representation ladder

The investigation does not privilege a scalar representation in advance. Candidate descriptions are evaluated in increasing structural richness:

1. **Native scalar coordinates.** Retain a scalar only when it carries information not already fixed algebraically by the native model and when uncertainty/refusal behavior is explicit.
2. **Modal or scale-resolved representation.** Promote when frequency-, scale-, redshift-, tracer-, or perturbation-resolved information is required to preserve behavior lost by a scalar summary.
3. **Coupled / conglomerate representation.** Promote only when relations among qualified components add information beyond the components considered separately.
4. **Refusal.** Refuse a proposed representation when it is redundant, non-identifiable, prior-dominated, model-imposed, unstable to admitted alternatives, or unsupported by available resolution.
5. **Need more information.** Distinguish absence of evidence from evidence of absence. Use this state when the requested distinction is in principle testable but the present dataset, covariance, model family, or holdout structure cannot resolve it.

## Core decision gates

### R0 — native-model sufficiency

Ask whether the candidate quantity is already an algebraic re-expression of the native cosmological model.

**ACCEPT for further testing:** candidate contains independent measured or inferred structure.

**REFUSE:** candidate is mathematically generated by already-used variables under the same assumptions and therefore cannot supply independent evidence.

**NEED MORE INFO:** dependence cannot be established because required covariance or model details are unavailable.

The DESI background result already supplies a concrete example: under flat GR matter + smooth DE, (q(a)) and (chi_delta(a)) are linked once the model is specified. Their coexistence is therefore not an independent capital-(Chi) detection.

### R1 — scalar adequacy

Ask whether a one-dimensional summary preserves the behavior required for the scientific question.

**ACCEPT scalar:** one coordinate retains the relevant ordering, transition structure, uncertainty and predictive information within the frozen question.

**REFUSE scalar:** multiple transitions, branch dependence, scale dependence, multimodality or strong degeneracy destroy the needed information.

**NEED MORE INFO:** sampling or resolution is insufficient to determine whether the apparent scalar adequacy is genuine.

The BAO-only (w_0w_a) multiple-(q)-crossing result is already an empirical scalar-limit example.

### R2 — modal / scale-resolved necessity

Ask whether resolved structure adds reproducible information beyond the accepted scalar and native parameters.

Candidate observables may include growth, clustering, response, transfer or covariance-supported components such as (D(k,a)), (f(k,a)), (fsigma_8(a)), (P(k,a)), and qualified analogues.

Promotion requires a frozen comparison against a lower-order representation and must survive nuisance/model alternatives relevant to the same observable.

### R3 — coupling / conglomerate necessity

Ask whether the relation among qualified components carries information beyond each component separately.

A coupled representation is not earned merely because two curves covary. It must improve prediction, compression with preserved information, anomaly localization, cross-dataset transport, or a preregistered discriminating task.

### R4 — competing-explanation survival

Every promoted representation must be tested against relevant native alternatives before a Stability Architecture interpretation is advanced. Current required adversaries include, when dataset-matched:

- flat (Lambda)CDM / GR;
- dynamical-DE parameterization or reconstruction;
- neutrino-mass freedom;
- modified gravity;
- supernova-sample dependence;
- dark-sector interaction models where a reproducible likelihood is available;
- known model/projection/systematic effects.

Failure against an adversary does not disappear from the record. It narrows the claim.

### R5 — prospective falsifiability

A promoted representation must have at least one prospective observation or held-out analysis that can make it fail.

A result that can always be reinterpreted after the fact is not a qualified diagnostic.

### R6 — executable-tool emergence

Software is promoted only when the preceding gates exhibit enough stable, repeatable structure to implement them without silently introducing new scientific authority.

The executable tool, if earned, should return an evidence record such as

[
{	ext{SCALAR ADEQUATE},;
	ext{MODAL REQUIRED},;

	ext{REFUSED},;
	ext{NEED MORE INFO}}
]

together with reasons, assumptions, uncertainty, failed gates and the next discriminating observation. It must not emit a single universal score that erases domain-specific structure.

## Tool-emergence acceptance criteria

A computational diagnostic is admitted only if all of the following hold:

- at least two scientifically distinct cosmological test cases exercise the same decision logic;
- one or more explicit refusal cases are correctly preserved;
- the output changes when scientifically material information is removed or altered;
- the result is not equivalent to a pre-existing native model-selection statistic under a new name;
- uncertainty and non-identifiability propagate into the output;
- thresholds or branch rules are frozen before the held-out result is inspected;
- a scientist can reconstruct why a state was assigned from durable records;
- automation does not decide whether a new scientific hypothesis should be introduced.

If these conditions do not hold, the methodology remains the final tool for this stage.

## Novelty boundary

Existing cosmology already contains model comparison, null tests, consistency tests, non-parametric reconstructions, Bayesian evidence, profile likelihoods and probe-combination diagnostics. The novelty target is therefore not "a method that compares cosmological models." The candidate contribution is narrower: an explicit representation-qualification and refusal framework that asks how much stability structure the evidence licenses before interpretation, preserves scalar failure as information, and treats falsifiability and NEED-MORE-INFO as native outputs.

This novelty claim remains provisional until a formal prior-art gate is completed.

## Current external context to retain

DESI DR2 has published both parametric and non-parametric dark-energy analyses, so any method claim must be distinguished from existing reconstruction work. DESI's public DR1 full-shape products also expose (Lambda)CDM, (w), (w_0w_a), free-neutrino-mass and modified-gravity model families, making dataset-matched adversarial testing feasible. The 2026 DR2 Ly(alpha) full-shape result additionally demonstrates that adding shape information can materially change precision and shift central values relative to BAO-only analysis; this is directly relevant to the scalar-versus-resolved representation question.

## Permitted endpoints

The investigation may terminate with any of these scientifically acceptable products:

1. **Methodology only:** a reproducible representation-qualification and falsification procedure.
2. **Methodology + domain diagnostic:** an executable cosmology-specific implementation of stable gates.
3. **Methodology + refusal of automation:** evidence that scientific judgment or domain-specific structure prevents a reliable executable diagnostic.
4. **Methodology + null scientific result:** the procedure works, but no additional Stability Architecture representation survives native cosmology and adversarial controls.

No endpoint is treated as failure merely because it does not produce software.
