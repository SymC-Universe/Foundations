# SA + SI + DM + DE Conglomerate Admission Test v0.1

**Status:** PROSPECTIVE, NOT ACTIVATED UNTIL INPUT LANES ARE QUALIFIED  
**Date:** 2026-09-30

## Strategic question

Does combining Stability Arc (SA), Stability Inheritance (SI), dark-matter-side structure/growth information, and dark-energy-side expansion information create a scientifically useful representation that adds information beyond the qualified component analyses?

If not, the conglomerate is not promoted merely because the pieces form a coherent narrative.

## Null

The apparent unified picture is an interpretive synthesis of already-known relations. Any useful inference can be reproduced from the component analyses, native cosmological models, and existing expansion-growth / degeneracy-breaking methods without a new conglomerate representation.

## Candidate conglomerate

Let the qualified component state be represented schematically by

\[
A = \text{SA-qualified transition / stability coordinates},
\]

\[
I = \text{SI-qualified inheritance / history variables},
\]

\[
M = \text{DM-side growth / clustering / potential structure},
\]

\[
E = \text{DE-side expansion / acceleration structure}.
\]

A candidate conglomerate is

\[
C = C(A,I,M,E).
\]

No fixed formula for C is licensed in advance.

## Admission criterion

The conglomerate is scientifically useful only if its relational structure adds reproducible information beyond the marginals and native models:

\[
\mathcal I(Y;C\mid A,I,M,E,\text{native model})>0
\]

or an equivalent preregistered held-out predictive/discriminating improvement.

Possible targets Y must be concrete and prospective, for example:
- later or held-out growth behavior;
- cross-scale response;
- a transition location or topology not fixed by the native model;
- discrimination among dataset-matched dark-sector explanations;
- a transportable prediction across independently held-out cosmological probes.

## Automatic REFUSE conditions

Refuse the conglomerate if any of the following occurs:

1. all apparent structure is algebraically inherited from LambdaCDM/GR or the chosen DE/MG parameterization;
2. joint performance is reproduced by ordinary expansion-growth analyses;
3. gains vanish after conditioning on component marginals;
4. gains arise only from additional dimensionality or unequal model flexibility;
5. SI contributes no prospective information beyond ordinary transfer/history variables;
6. SA adds only a coordinate relabeling of known transitions;
7. the result is not robust to neutrino, MG, SN-sample, interaction, or relevant systematic adversaries;
8. no held-out target can be named before result inspection.

## NEED MORE INFO conditions

Return NEED_MORE_INFO when:
- SI has not yet produced a qualified measurable carrier in cosmology;
- the required covariance between component lanes is unavailable;
- component definitions are not observationally commensurate;
- the relevant scales/redshifts do not overlap;
- current data cannot separate native-model dependence from relational value.

## Promotion ladder

### C0 — component qualification
Each component must independently pass its own representation gate.

### C1 — pairwise conditional tests
Test A-I, A-M, A-E, I-M, I-E, M-E relations after conditioning on marginals/native variables.

### C2 — minimal subset search
Identify the smallest subset whose relation adds held-out information. Do not automatically retain all four components.

### C3 — full conglomerate challenge
Compare the best minimal subset against the full A-I-M-E representation. Full conglomerate is promoted only if it adds incremental value.

### C4 — matched adversarial transport
Evaluate across LambdaCDM/GR, dynamical DE, neutrino mass, modified gravity, and interaction alternatives where matched likelihoods exist.

### C5 — prospective holdout
Test on an untouched dataset/probe/realization.

## Scientific outcomes

- **REFUSED_SYNTHESIS_ONLY** — coherent picture, no incremental information.
- **MINIMAL_RELATION_SURVIVES** — a smaller pair/triple matters; full conglomerate not needed.
- **FULL_CONGLOMERATE_ADDS** — the full relation adds held-out value.
- **NEED_MORE_INFO** — scientifically unresolved.
- **COMPONENT_FAILURE** — one or more required lanes are not independently qualified.

## Strategic rule

The conglomerate is not a publication target by default. It is an empirical question submitted to the Representation Qualification Method. If it is merely a synthesis, preserve it as conceptual context and stop. If a minimal relational subset adds reproducible prospective information, investigate that subset rather than protecting the grand picture.
