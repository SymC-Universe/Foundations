## Figure-governance rule

Every figure must answer a specific scientific question, show the evidence class directly, and remain traceable to source-of-record data. No figure may manufacture a physical threshold, a universal chi boundary, a system scalar, or an inheritance classification not earned by the underlying record.

Rare/failure cases must be shown in proportion to their role. Functioning interiors and limits should appear together where that pairing is scientifically essential.

## Figure 1. What would count as substrate inheritance?

### Scientific question

How does SI distinguish ordinary substrate influence from a stronger prospective inheritance claim?

### Proposed structure

A left-to-right evidence ladder:

`independent parent characterization`

→ `prospectively frozen carrier/subspace correspondence`

→ `child prediction before target reveal`

→ `independent child object`

→ `parent intervention/counterfactual`

→ `specificity controls`

→ `influence / conditional inheritance / inheritance / refusal`

Across or below the ladder, show complementary starting reporting channels:

- scalar where licensed;
- modal/vector/subspace;
- conglomeration/system organization;
- open/additional native objects where needed.

Uncertainty, observability, identifiability, and refusal should be shown as cross-cutting rather than as one final error bar.

- `README.md`
- GOM migration record

### Evidence class

Architecture / methods diagram. No result values.

### Avoid

- a single funnel into “chi”;
- implying all systems instantiate exactly three representations;
- making influence look like a failed version of inheritance rather than a legitimate lower evidence class.

## Figure 3. What compression loses

### Scientific question

Which information can be lost when a richer governing description is compressed?

### Three demonstrated examples

**Scalar compression:** distinct coupling directions reproduce the same scalar self-energy at one frequency.

**Lineage compression:** direct carrier reconvergence is exact, while sequential row-normalized flow retains a nonzero discrepancy.

**Subsystem reduction:** exact dynamic reduction preserves the declared response, while approximate reductions lose information in selected regimes.

### Proposed visual grammar

For each example:

`richer object -> compressed object -> information retained / information lost -> additional observation that resolves the ambiguity`

### Source

- `identifiability_validation.py` / result record
- FM3 result
- FM4 result

### Evidence class

Synthetic methodological limit synthesis.

### Avoid

Do not imply “compression is bad.” The conclusion is task-dependent sufficiency, not a blanket rejection of scalars or model reduction.

## Main-text versus supplement rule

Main text should contain Figures 1-4 if space permits because they carry the conceptual and evidentiary spine of the manuscript. Dense seed-level surfaces, full sensitivity distributions, condition-number maps, and exhaustive known-bad cases should move to supplement/reproducibility material while remaining reader-checkable.

## Figure artifact policy at evidence-complete draft

Once a figure specification is frozen:

1. generate from source-of-record data, not copied numbers;
2. preserve the generation script;
3. record source result hash(es);
4. hash PDF/PNG/SVG outputs as applicable;
5. add figure-to-claim entries to the manuscript evidence matrix;
6. run a semantic audit that axes, legends, units, and captions describe the computed object;
7. preserve prior figure versions if scientific meaning changes.
