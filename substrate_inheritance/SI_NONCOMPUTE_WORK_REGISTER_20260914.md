## F. Stop condition for non-compute work

A non-compute task stops when it:

1. closes the declared provenance/reproducibility/communication gap;
2. identifies a bounded unresolved scientific question;
3. shows that existing literature already answers the question;
4. reaches a point at which further progress would require opening new result-dependent evidence or changing frozen science; or
5. becomes redundant with an existing source-of-record object.

The goal is continuous scientific progress without turning documentation into busywork.
