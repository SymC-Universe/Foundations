Lowercase chi remains refused because the locked source table does not provide same-condition `omega0`.

## What failed

### FIG3 carrier map

The v0.1 schema-only parser assumed the complete M-R map occupied columns A:C.

After execution that extraction contained only 21 rows and paired a monotonically changing q value with a monotonically changing energy value. The workbook schema contains roughly one thousand numeric cells across 40 columns for each experimental panel.

Therefore the v0.1 A:C extraction is not a faithful representation of the 2D `S(Q,E)` map.

Official status:

`PARSER_INADEQUATE`

### FIG4 4a fit residual

v0.1 compared the source INS series directly with the source plotting curve labelled `DHO fit`.

The figure caption states that curves are vertically offset for clarity. The source workbook does not establish that plotting-series offsets/backgrounds are removed in a way that licenses a standardized goodness-of-fit calculation.

Official status:

`NOT_ADMISSIBLE_FOR_MODEL_ADEQUACY`

The published DHO curve can still be reproduced visually, but v0.1's RMS standardized residual is not scientific evidence.

## Consequence

D02A v0.1 is a useful failure:

- source integrity passed;
- linewidth extraction passed;
- chi correctly refused;
- carrier-map extraction failed;
- source-fit goodness-of-fit inference was overreaching.

A v0.2 parser may now be developed from a full workbook-layout diagnostic, but it is explicitly post-result development evidence.
