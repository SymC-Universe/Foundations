# 4. Cross-project changes required for chi-architecture P0

The review changes the design requirements for the next genuinely evaluative chi-architecture experiment.

## A. Model adequacy becomes a first-class pre-outcome gate

Before interpreting S/M/C/R disagreement, the native model must have a predeclared adequacy assessment. Otherwise estimator failure can masquerade as architecture failure or architecture discovery.

Adequacy cannot be invented after an unfavorable result. Its diagnostics and consequence for inference must be fixed before the decisive output is opened.

## B. Observable architecture is allowed to be smaller than latent architecture

A hidden or weakly observable component must not be manufactured merely because the simulator or theoretical model contains it. Claims are bounded by what the measurement/operator identifies.

## C. Identifiability propagates upward

A lower-level refusal propagates into any higher-level object that requires the refused information. A conglomerate cannot restore individual modal identity by notation alone.

Under crowding/degeneracy, use invariant subspaces, projectors, clusters, or return UNRESOLVED/PARTIAL.

## D. Independent units and exchangeability must be explicit

Feedback/recovery studies must define the independent experimental unit before permutation or uncertainty calculations. Technical replicates, repeated measures, ordered conditions, and biological replicates are not interchangeable.

Permutation/null design must preserve the dependence structure that exists in the experiment.

## E. Shared-input algebra must be audited before predictive interpretation

If target Y and any candidate predictor S/M/C/R share a denominator, baseline, normalization, sample-derived reference, or other mathematical input, quantify the induced dependence before interpreting prediction as biological/physical information.

A favorable association created by shared construction does not support the architecture.

## F. Outcome-blindness language must reflect actual provenance

If published outcome descriptions, captions, or qualitative behaviors have already been read, the project cannot later claim complete outcome blindness. Numeric holdout blindness and rule-freeze timing may still be valid and must be described precisely.

## G. Native comparator remains task-specific and must be frozen before evaluation

There is no single global comparator. NSD suggests DMD for its declared structural task; GRI has AJIVE/MOFA2 and predictive comparator obligations; Chemistry has native barrier/rate/network models.

The next architecture experiment must identify the strongest fair comparator for its exact native task before opening the decisive comparison.

## H. Atlas must remain read-only with respect to Engine rules

An Atlas may supply external reference context only after the Engine/System Model is fixed. Atlas values cannot tune Engine thresholds, select favorable coordinates, or validate evidence from the same lineage.

Each decisive Atlas reference needs an independence status/grade. `NO_ATLAS_MATCH` is an allowed result.

## I. Evidence quality must remain multidimensional

Do not combine provenance, condition match, mechanism identity, estimator adequacy, uncertainty, and outcome agreement into a compensatory master score. A failure on one required axis remains visible even when other axes are strong.

## J. Network/system representation is admitted only when native science requires it

The Chemistry Atlas shows that some processes are genuinely network-resolved. This supports allowing topology to become richer than a scalar or single mode, but it does not justify inserting network structure where the native problem does not require it.

## K. Future Engine maturity should include mutation and clean-room qualification

Known-bad tests are necessary but not sufficient for later production maturity. Deliberate mutation tests should prove important guards are actually caught, and final production qualification should include fresh-environment reproduction and stale-cache/checkpoint refusal.

# 5. Effect on the current chi-architecture hypothesis

## What became stronger

The **methodological basis** became stronger:

- useful architecture can survive without an admitted scalar chi;
- scalar/modal/system layers can fail separately;
- whole-system description can require richer topology than one local quantity;
- nonidentifiability must propagate rather than being averaged away;
- native comparators and model adequacy are indispensable;
- refusal/HOLD states can be scientifically informative;
- evidence independence and shared-input circularity are concrete, recurring threats across domains.

## What did not become stronger

The review does not supply new confirmatory evidence that:

- architectural Chi is a cross-regime natural object;
- scalar/modal disagreement is compensatory;
- feedback is the mechanism behind GRI architecture;
- NSD contains the proposed feedback architecture;
- Barrier Atlas evidence integration is a physical conglomerate;
- one scalar chi exists across these domains;
- any universal stability law exists.

The current generalized hypothesis therefore remains **P0 exploratory with unpaid promotion debt**.

## What became less available for future confirmation

Because GRI, current Barrier Atlas development, and NSD have now informed generalized architecture design, they are increasingly unsuitable as pristine confirmation targets for any rule learned from them.

They remain valid for calibration, falsifier construction, method qualification, and domain-specific follow-up. Confirmatory cross-regime claims require new untouched evidence or explicitly separated future data/perturbations that were not used to formulate the mapping.
